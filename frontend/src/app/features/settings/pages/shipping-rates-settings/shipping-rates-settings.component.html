2. Configuración de cálculo para medida personalizada

Ancho máximo (cm) Largo máximo (cm) Alto máximo (cm) Peso máximo permitido (kg)
Factor volumétrico
  • El sistema calculará automáticamente el peso volumétrico con la fórmula:
    Peso volumétrico = (Largo × Ancho × Alto) / Factor volumétrico
  • Luego compara:
    Peso cobrado = máx(Peso real, Peso volumétrico)
  • Y busca entre las tablas de tarifas el precio correspondiente a ese peso cobrado.
